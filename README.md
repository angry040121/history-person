# 测测你的灵魂对应哪位中国历史人物

一个纯前端、无需后端的国风趣味人格测试网页。从日常习惯、处事方式、社交模式、情绪反应和兴趣偏好出发，通过 40 道生活化单选题，为你匹配对应的中国历史人物。

> 本项目仅供娱乐，不代表历史定论，也不是专业心理诊断。

## 玩法

- 共 **40** 道单选题，逐题作答。
- 每题选项对应不同性格维度，提交后自动加权计分。
- 根据综合得分匹配七类历史人物之一。

| 维度 | 历史人物 |

| 侠客 | 荆轲 |
| 诗人 | 李白 |
| 将领 | 霍去病 |

每位结果包含：性格特点、匹配理由、隐藏优势、趣味彩蛋、专属文案与七维画像，页面版式适合截图分享。

## 技术说明

- 单文件实现：HTML / CSS / JavaScript 全部内联在 `灵魂历史人物测试.html` 中。
- 原生 JavaScript，无框架、无构建工具、无外部接口依赖。
- 响应式布局，适配手机与电脑。
- 本地双击 HTML 文件即可运行。

## 目录结构

```
.
└── 灵魂历史人物测试.html   # 完整可运行的测试页面（单文件）
```

## 本地运行

直接用浏览器打开 `灵魂历史人物测试.html`，或启动一个本地静态服务：

```bash
# 任选其一
python3 -m http.server 8080
# 然后访问 http://localhost:8080/灵魂历史人物测试.html
```
